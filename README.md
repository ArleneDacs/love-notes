# Love Note Studio

A single-page app for writing a personal love note to everyone on a list and printing them as folded cards.

- Pick a name, write the letter, and see it on a 3D card as you type.
- Choose a card style (theme, cover art, lettering, handwriting) for all cards or for one person.
- Print preview shows exactly how each sheet will come out, then download a PDF to print double-sided.
- Everything is saved in the browser (letters in local storage, photos in IndexedDB). Nothing is sent to a server.

## Run it

It is one file. Open `index.html` in a browser, or deploy the folder as a static site (Vercel, Netlify, GitHub Pages).

## Deploy on Vercel

Import this repository in the Vercel dashboard and press Deploy. No build step or settings are needed; Vercel serves `index.html` as a static site.
